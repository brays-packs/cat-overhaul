# Bray's "Cat Overhaul"
Currently adds 8 new cat breeds that spawn naturally in villages and 2 new cat breeds that can be found in The Nether! In versions after the Tiny Takeover, all cats have unique kitten textures as well.

![Bray Cat Overhaul Banner](https://cdn.modrinth.com/data/Nwilg3bR/images/2a7e03bd71ccb7232f050b711eb7d3bb2944a745.png)

### Resource Pack is Required

The supplied RP is required for this datapack to work and can be downloaded along with any version of the datapack under the 'Supplementary Resources' section. If you download **Bray's Cat Overhaul** as a mod, the RP will already be available in your resource packs list in-game.

<summary>TECHNICAL INFORMATION</summary>
  
## HELLCATS
  
Hellcats are occasionally spawned in place of a blaze in the Nether. Every time a blaze spawns, it has a **5%** chance of becoming a Hellcat instead.

Hellcats naturally spawn with Fire Resistance

--------------------

## WITHERCATS

Wither Skeletons have a chance to drop a witherfish when killed by a player.

Base: **5%**

Looting I: **6.6%**

Looting II: **8.3%**

Looting III: **10%**

If you feed the witherfish to a Hellcat, it will be transformed into a Withercat instead. You may revert this interaction by using a Blaze Rod on a tamed Withercat.
